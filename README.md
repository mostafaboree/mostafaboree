### 🛡️ Service Center — insurance & installment sales
Designed and built a full module of **~30 new documents**:
- **Insurance** — programs, policy orders & issuance, delivery, receipts, renewals, cancellations, value/period adjustments, purchase invoices and grouped policy requests, each with status tracking, validation and accounting configuration
- **Installments** — installment types, quotations, installment parties and program status
- **Master data** — insurance companies, finance companies and external agencies

### 🛒 E-commerce marketplace integrations
- **Amazon SP-API** — clients for the Finances, Reports and Notifications APIs; order-change notifications consumed from **AWS SQS**; returns imported from reports and refunds, priced from financial events
- **Salla** — migrated order and bundle-item retrieval off the deprecated API; fixed component pricing for product groups and fixed shipments
- **Zid** — fixed paging
- **Shared layer** — e-commerce site grouping, webhook event processing and item-linking utilities

### ⚙️ Core ERP & platform
- **Task queue system** — `TaskQueue`, `PendingTaskSchedule`, `TaskQueueRegistrar`
- **Notifications** — delegation to stand-ins, bulk messages from a query, **Unifonic** SMS provider
- **Accounting** — fiscal-year status updates, prepaid expense contracts with ledger settings, payment-voucher logic
- **Supply chain** — grouped stock transfer requests, coupon sales-order returns, executed/remaining quantity migration
- **CRM** — activity types, lead classification, rejection reasons, main categories, visits & calls
- Plus work in real estate, contracting, HR, fixed assets, manufacturing and **Vue** UI fixes
